Halaman ini mensimulasikan konten website aktif tempat ekstensi To-Do List Anda bekerja. Saat ekstensi diaktifkan melalui toolbar atau floating button di pojok kanan bawah, panel overlay akan meluncur masuk menimpa layar tanpa merusak layout website ini.

Silakan klik tombol "Toggle Panel" di header atau tombol bulat biru di kanan bawah untuk membuka/menutup panel. Anda dapat mencoba mengetik tugas baru, mencentang checkbox untuk melihat animasi coret, memfilter status (Semua / Aktif / Selesai), serta mengganti tema tampilan di atas secara langsung.

🛡️ Terisolasi via Shadow DOM

Gaya tampilan To-Do List tidak akan pernah terpengaruh oleh CSS website host (seperti Bootstrap, Tailwind, atau warna global website).

⚡ Cepat & Ringan

100% Vanilla JS dan CSS modern tanpa dependency atau bundle overhead, menjamin response time instan.
